# Web MCU Klinik Pakisaji Cardiovascular Center

Prototype sistem Medical Check Up (MCU) berbasis web untuk Klinik Pakisaji Cardiovascular Center.

## Tujuan Prototype
- Menguji alur kerja MCU
- Menguji kebutuhan Petugas MCU
- Menguji kebutuhan Dokter
- Menguji kebutuhan Laboratorium
- Menguji kebutuhan Admin
- Memperoleh feedback sebelum sistem dikembangkan lebih lanjut

## Status Project
**Phase 1 — Stabilization & Foundation**
Status: Selesai / siap dilanjutkan ke Phase 2 setelah testing manual.

## Roadmap
- **Phase 1:** Foundation, Login, Role, Dashboard
- **Phase 2:** Peserta MCU
- **Phase 3:** Pemeriksaan MCU
- **Phase 4:** Laboratorium & Pemeriksaan Penunjang
- **Phase 5:** Dokter & Kesimpulan
- **Phase 6:** Hasil MCU & PDF
- **Phase 7:** Testing & UI Polish
